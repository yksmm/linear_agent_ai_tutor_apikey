# 线代启明星：线性代数核心概念与证明辅导智能体
> 项目：面向大一《高等代数（邱维声第四版）》启发式AI辅导Demo

## 项目简介
本系统是基于阿里云百炼多模态大模型开发的教育智能体，使用 Python + Streamlit 搭建网页端。
学生上传线性代数证明题图片，AI不会直接给出完整答案，遵循教材顺序，往前追溯基础定义、定理，通过提问引导学生自主推导。
系统自动记录学情到美化后的Excel表格，仅留存知识点、定理混淆点、不明白的内容；配套教师学情面板，支持查看学生学习情况。

## 核心功能
1. 图片拖拽上传，识别线代证明题目
2. 启发式引导，依据邱维声《高等代数》第四版，优先回顾前置基础概念
3. 学情自动归档，Excel自动美化，记录知识点、混淆概念、知识卡点
4. 教师学情面板，查看全班学习诊断记录
5. 一键切换下一题，重置页面所有作答内容

## 运行环境
- Python >= 3.10
- 依赖包：streamlit、pillow、openpyxl、dashscope
